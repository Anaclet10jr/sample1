# More Programming Projects

A second collection of practical beginner-to-intermediate projects. These are different from the first portfolio pack.

## Projects
1. **Java — Library Management:** Add books, list books, and search by title using classes and an ArrayList.
2. **HTML/CSS — Responsive Landing Page:** A clean landing page for a fictional technology club.
3. **JavaScript — Quiz App:** Answer multiple-choice questions and see your score.
4. **PHP/MySQLi — Inventory Manager:** Add products, view stock, and delete products using prepared statements.
5. **Python — Expense Tracker:** Record expenses and calculate the total.
6. **C — Student Marks:** Enter marks, calculate the average, and assign a grade.
7. **SQL — Inventory Database:** Create the database and products table used by the PHP project.

## Run the projects

- Java: `cd java-library` then `javac LibraryApp.java` and `java LibraryApp`.
- HTML/CSS: Open `tech-club/index.html` in a browser.
- JavaScript: Open `quiz-app/index.html` in a browser.
- PHP: Install XAMPP, copy `php-inventory` into `htdocs`, start Apache and MySQL, run `sql/inventory.sql` in phpMyAdmin, then visit `http://localhost/php-inventory/`.
- Python: `python expense_tracker.py` from `python-expenses/`.
- C: `gcc student_marks.c -o student_marks` then run the executable.
- SQL: Run `sql/inventory.sql` in MySQL/phpMyAdmin.
